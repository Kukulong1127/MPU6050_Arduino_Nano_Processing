# Demonstration video

Place the final demonstration here, preferably as:

- `final-demo.mp4` for the full-quality recording; and/or
- `final-demo.gif` for an inline preview in the repository README.

A useful 30–60 second recording should show:

1. the physical MPU6050 and Arduino Nano;
2. the sensor moving while the panoramic view follows;
3. switching between keys `1`, `2`, and `3`;
4. pressing `R` to recenter the camera; and
5. optionally starting the stationary drift test with `T`.
